# Changelog

## v1.0.0 — Fit Mamma (2026-11-06)

First release, forked from Project 85 v0.15.0.

- New name, icon (heart + trend line) and warm light theme with larger text.
- Her plan to Eid (10 Mar 2027): 1,500 kcal / 110 g protein, steps 6k → 8k.
- First-run profile form: weight, height, birth year and goal are entered on the phone, never stored in the repo.
- Five-day body-part gym split with exercise animations and Hindi YouTube demo links; Saturday walk, Sunday rest.
- Phases: Learn, Build, New Year deload, Strong, Ramadan mode (sehri/iftar guide, 4 lighter sessions after iftar), Eid.
- Desi food library with portion picker (½ / 1 / 1½ / 2).
- Celebration stickers: workout done, new best, new lowest weight, each kg lost, goal.
- English / Urdu language switch for the main screens.
- Removed: cigarette tracking, weekly report sharing, Project 85 PDFs and birthday copy.
